# Science Quiz UI 设计稿

> 状态更新：用户已确认 Schema v1 和本设计，并授权进入开发。以下保留设计阶段的交付边界；当前实现与测试证据见 [开发验证记录](../development-validation.md)。

## 设计定位

依据 `docs/PRD.md` 的儿童用户、五个页面和本地优先要求设计。面向约 10 岁、能够独立阅读的儿童；友好、清晰、平静、有探索感。新建视觉方案，尚无现有品牌需要迁移。

采用 design-taste-frontend 的视觉一致性、排版与状态设计原则。该技能不覆盖多步骤产品流程，因此首页不套营销 Hero，答题页不套展示型网站的布局限制。设计变化 4、动效 2、密度 3。原生 CSS 语义令牌是后续实现基础，遵循 PRD 的 Vue 3 / TypeScript / Vite，不引入 React、Tailwind 或大型设计系统。

本轮交付静态高保真设计板和交互规格。图中的学习结果、错题数均为示例。Schema 仍是候选，UI 使用共享材料方案展示，不表示已确认数据契约；不实施应用、同步服务或题库修订。

## 页面与操作

| 页面 | 首要任务 | 内容与操作 |
|---|---|---|
| Home | 选择主题 | “今天想挑战什么？”；主题名称、简短介绍、题量、已掌握数量；“开始挑战”；“我的错题”入口 |
| Topic | 了解本次练习 | 主题说明、题型、可练题数；材料练习明确“共 5 题，共用一份材料”；“开始练习” |
| Quiz | 完成当前题 | 当前题数、题型、材料、题干、选项、提交；提交后在原位置出现反馈 |
| Result | 理解练习结果 | “完成！”、答对／答错题数；“查看错题”“再练一次”“返回主题”；不画复杂统计图 |
| Wrong Questions | 再练错题 | 主题筛选、题干摘要、最近结果；“再练错题”；底部独立的可选 GitHub 同步区 |

主导航只保留“主题练习”和“我的错题”。答题时收起主导航，保留“返回主题”和进度。新用户不要求姓名、登录或头像。主题数与题量来自正式 manifest，设计板的四个主题仅展示布局，不定义最终分类。

## 材料与答题

桌面／横向平板：最大内容宽度 1120px；材料与答题区约 45:55。材料标题和实验条件在上，数据表在下，题干与选项独立成区。材料区不使用嵌套滚动。

手机：小于 768px 改为单列，左右留白 20px；先材料再问题。材料默认展开，可通过“收起材料／展开材料”按钮折叠；切换组内题目保留展开状态。宽表局部横向滚动，页面本身不横向溢出。底部操作区预留安全区与占位空间，不遮住最后一个选项或反馈。

用真实第 161 题展示材料模式，长度／频率保持 8/240、12/180、16/145、20/120，明确单位。材料插图不是答题必需装饰，不补造实验装置图。普通题省略材料区，题干宽度控制在约 30 个汉字。判断题两个大选项；多选题明确“可选择多个答案”，使用方形选中标记；单选使用圆形标记。

初始“提交答案”不可用，同时文字提示“先选择一个答案”。选中后只改变选中状态，不自动提交。提交中防重复点击；正确答案用图标和“答对了”文字表达，不仅依赖颜色。错误反馈保持温和，并明确“这次还不对”。

反馈策略为设计建议：首次提交计入本轮结果，错题允许“重新选择”或“查看解析”；重试答对不回改首次结果。查看解析后提供“下一题”。提示必须来自已审阅内容，没有提示字段时不临时生成。设计板对 161 题的数据提示是拟议文案，仍需内容审阅。逐题解析缺失时，生产题库应在发布前被拦截。

## 视觉令牌

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面底色 | `#F4F7F6` | `#14221E` |
| 内容表面 | `#FCFDFB` | `#1E332B` |
| 主文字 | `#193D35` | `#EDF5F0` |
| 次文字 | `#4B625A` | `#B8CEC2` |
| 主按钮底色／强调色 | `#246B58` | `#91D3B7` |
| 主按钮文字 | `#FCFDFB` | `#14221E` |

整页跟随系统主题，同一页面不混用明暗区块。正确／错误通过文字、符号和边框区分，不添加大面积红绿刺激色。圆角规则固定：内容面板 16px，按钮／选项 12px。只有真实可点击主题入口使用轻微悬浮效果。

中文字体使用系统无衬线栈：PingFang SC、Microsoft YaHei、sans-serif。页面标题 28-36px，题干 22-26px，选项 20px，正文 18px，辅助信息至少 14px；中文正文行高 1.65。触控区域至少 48px 高，选项至少 64px，选项间距 12px。表格数据对齐，保留单位和表头。

首页允许少量科学物件插画辅助辨认主题，不把它们当作题图。正式图标统一选用一个图标库，装饰图对屏幕阅读器隐藏。当前设计板是栅格概念稿，不能直接作为正式图标或可访问组件使用。

## 状态清单

| 状态 | 展示与恢复方式 |
|---|---|
| 加载题库 | 与主题／选项布局同形的静态占位，文字“正在准备题目” |
| 题库加载失败 | “题目暂时没能打开”；“重试”“返回主题”；保留已保存记录 |
| 尚无学习记录 | 主题显示“尚未开始”，不伪造掌握率 |
| 没有错题 | “这里还没有错题”；“去练习”，同步操作不可用 |
| 全部答对 | 结果页“这次全部答对了”；主操作“再练一次”，不突出空错题入口 |
| 本地保存失败 | “这次记录暂时没能保存”；保留当前答题内容并提供重试，不能同时声称已保存 |
| 待同步 | “3 个错题待同步”，仅明确点击后发送 |
| 同步中 | “正在同步”，按钮防重复提交，答题功能仍可使用 |
| 同步成功 | “同步成功”，随后显示“已同步” |
| 同步失败 | “同步失败，本地数据已保存”；“重新同步”，仅在本地保存成功时使用该文案 |
| 离开未完成练习 | 提示已提交答案是否保存；“继续练习”“返回主题”，不使用浏览器连续弹窗 |

同步入口位于错题本，保持次要层级。凭证配置不进入儿童操作流程；不展示令牌输入框，不承诺跨设备实时同步。无网仍可继续已经可用的题目，首次离线且题库未缓存时显示题库不可用说明。

## 可访问性与交付边界

后续实现使用原生按钮、radio／checkbox 和语义表格；表头关联数据单元格。选项整行可点击，键盘可操作，焦点边框清楚。提交后的反馈通过 live region 通知，下一题把焦点移至题干；折叠材料按钮提供展开状态。

动效仅用于点击反馈和状态过渡，120-180ms；关闭动态效果时立即切换，无自动漂浮、倒计时或庆祝动画。按钮标签单行，长题干完整显示。

本轮只验证了设计令牌的文本对比度并核对 PRD 页面／状态覆盖。静态图片不是运行中的界面，尚未进行键盘、屏幕阅读器、响应式浏览器测试或 Lighthouse 测试，不能据此声称性能和可访问性验收已通过。

对比度计算记录：浅色主文字／页面 11.07:1，次文字／表面 6.44:1，主按钮 6.20:1；深色主文字／表面 12.10:1，次文字／表面 8.09:1，主按钮 9.56:1。以上为令牌计算，实际实现仍需检查禁用、聚焦及图片覆盖等具体状态。
