## 全局练习设置

右上角“练习设置”输入正整数，默认 10，存入独立的本地设置键。各主题、错题练习以及“再练一次”使用设置数量；改变当前练习中的设置不会改动本轮题目。再次练习从本轮来源题池重新抽题，因此增加数量后能抽取更多题，而非仍受上一轮题数限制。

题库不足时使用实际题数。材料组保持完整和顺序，可能超过设置数或使本轮少于设置数。点选具体材料组与错题单题时，按用户明确选择的题目练习。设置弹窗说明上述例外，支持键盘、Esc 取消和焦点返回。保存失败显示错误，继续使用原设置，不影响学习记录。

移动端品牌和右上角操作同排，主导航移至第二排；设置按钮触控区域为 48×48 px。沿用项目明暗主题令牌。
